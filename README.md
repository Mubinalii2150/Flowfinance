# FlowFinance

FlowFinance is a Personal Finance Management System developed using HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Features

- User Registration
- Secure Login (JWT Authentication)
- Add Transactions
- Edit Transactions
- Delete Transactions
- Dashboard
- Financial Reports
- Income vs Expense Charts
- Expense Category Pie Chart
- AI Financial Insights

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- Chart.js
- JWT
- Bcrypt

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/FlowFinance.git
```

Go to project

```bash
cd FlowFinance
```

Install packages

```bash
npm install
```

Start server

```bash
node server.js
```

Server runs on

```
http://localhost:5000
```

## Database

Create database

```sql
CREATE DATABASE flowfinance;
```
